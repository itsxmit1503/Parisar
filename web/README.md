# PARISAR Web Portal

Web client for **PARISAR (परिसर)** — Dr. Harisingh Gour Vishwavidyalaya (DHSGSU).

### Direct Android APK Download
Download the official Android release directly from GitHub:  
[**Download `parisar-v1.0.0-release.apk`**](https://github.com/itsxmit1503/Parisar/raw/main/release/parisar-v1.0.0-release.apk)

### Technology Stack
- Next.js 16 (App Router & Turbopack)
- React 19
- TypeScript
- Tailwind CSS v4
- Lucide Icons
- QRCode Generator

### Development
```bash
npm install
npm run dev
```

### Production Build
```bash
npm run build
npm run start
```
